# Satria Portfolio

A modern, responsive portfolio website showcasing the skills, projects, and professional experience.

## **Technologies Used**
- Astro
- Tailwind CSS

## **Project structure**
```
public/
├── svg/
└── assets/
    └── images/
src/
├── assets/
├── components/
│   ├── ui/
│   ├── layout/
│   └── sections/
├── layouts/
├── pages/
├── styles/
└── utils/
```

## **Features**
- Responsive design
- Animated UI elements
- Dark/light mode
- Project showcase
- Contact form
- Performance optimized

## **Local configuration** 
1. Clone the repo:  
```
git clone https://github.com/garaven/satria-portfolio
```
2. Install dependencies:
```  
npm install
```
3. Start the development server:
```  
npm run dev
```
4. Open your browser and navigate to:
```
http://localhost:3000
```

## **Deployment**
This portfolio is configured to be deployed on Vercel.

1. Push your changes to GitHub
2. Connect your repository to Vercel
3. Vercel will automatically build and deploy your site
